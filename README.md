# BMA Abschlussprojekt: Emulation mit Ayn Thor

Dieses Verzeichnis enthält die LaTeX-Umsetzung der Word-Vorlage für die Berufsmaturitätsarbeit (BMA) an der Berufsmaturitätsschule Zürich.

## Dateien

- [`main.tex`](file:///c:/BMA_Ayn_Thor/main.tex): Das vollständige LaTeX-Dokument mit allen Kapiteln, Tabellen, Checklisten und Formatierungen.

## Kompilierung

Das Dokument kann mit jedem gängigen LaTeX-System kompiliert werden (z.\,B. **TeX Live**, **MiKTeX**, **MacTeX** oder online über **Overleaf**):

```bash
pdflatex main.tex
pdflatex main.tex  # Zweiter Durchlauf für Inhaltsverzeichnis und Hyperlinks
```

Alternativ werden auch **LuaLaTeX** und **XeLaTeX** unterstützt.
